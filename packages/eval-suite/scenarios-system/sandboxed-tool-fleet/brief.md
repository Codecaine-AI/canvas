# Sandboxed tool-execution fleet

We need a diagram of how our fleet of disposable execution environments works for agents that invoke tools and code. An agent sends the placement service an image and resource class. The service first claims a compatible environment from the warm pool, returning it immediately on a hit. On a miss, it selects a healthy host with capacity, provisions a cold environment, and keeps the request waiting until boot completes.

Each environment progresses through provisioning, ready, leased, idle, draining, and destroyed states. A lease has a fixed term and stays valid only while the agent sends renewal heartbeats. When renewals stop, the reclaimer takes the environment and destroys it; it never returns a reclaimed instance to the pool, because filesystem and process state from a prior tenant must not survive. Every environment also has an absolute maximum age. Image releases retire older instances by marking them draining and destroying them after active leases end, without interrupting live work.

Within a lease, every tool call receives a timeout, memory ceiling, CPU cap, and network policy. Egress is limited to allowlisted destinations through a proxy. The runtime kills an overlong call and reports a timeout rather than a tool error. It streams capped output to the agent, while durable files go to an artifact store keyed by session because local state is ephemeral.

The warm-pool supervisor watches host capacity, pool depth, and demand, then adjusts pre-booted supply. Repeated boot failures quarantine a host and remove it from placement. Per-tenant quotas limit concurrent environments and aggregate runtime; requests beyond either limit wait fairly instead of consuming capacity reserved for other tenants. Operations monitor boot latency, lease reclamations, tool timeouts, and escape-attempt signals. The diagram should make clear how placement, lease lifecycle enforcement, resource and network controls, warm-pool management, host quarantine, and tenant quotas govern an environment from request through destruction.
