# SF blind system reconstruction

## SYSTEM PURPOSE
A retrieval-augmented ingestion and answering system that synchronizes permission-bearing source content, normalizes and versions it, chunks and embeds it into version-consistent retrieval stores, performs ACL-aware hybrid retrieval, produces grounded answers or declines when evidence is insufficient, handles ingestion and embedding failures, feeds answer-quality signals back into ingestion priorities, and rebuilds and atomically promotes index generations after an embedding-model change.
