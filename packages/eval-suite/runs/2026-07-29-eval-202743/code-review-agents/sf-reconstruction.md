# SF blind system reconstruction

## SYSTEM PURPOSE
A staged pull-request code-review procedure that gates eligible changes, assembles and ranks context, fans review out to five specialist reviewers, merges and verifies findings, publishes a policy verdict, learns from replies and disputes, restarts when the branch head changes, and degrades review scope when a daily repository budget is exceeded.
