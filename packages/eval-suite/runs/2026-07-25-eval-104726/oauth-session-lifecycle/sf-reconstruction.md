# SF blind system reconstruction

## SYSTEM PURPOSE
OAuth session lifecycle across services: initiate login, authorize with an external OAuth provider, process the callback and token exchange, map identity and issue an application session, validate application requests, provide just-in-time provider-token access, coordinate refresh, and invalidate or audit sessions when required.
