# SF blind system reconstruction

## SYSTEM PURPOSE
An offline evaluation harness that runs pinned scenario suites in bounded isolated workers, separates infrastructure faults from product-behavior failures, grades completed scenarios concurrently using retained evidence, assembles scorecards only across compatible fingerprints, detects run-to-run swings with bounded retries, records unstable variance, retains audit material, and promotes compatible runs into a baseline lifecycle.
