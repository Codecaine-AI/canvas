# SF blind system reconstruction

## SYSTEM PURPOSE
A backpressured event-data pipeline that accepts application events and partner batch uploads, authenticates and validates records, durably buffers them, performs ordered stateless transformation and sensitive-field removal, stores replayable data, loads successful records into a warehouse through idempotent batches, serves tenant query results, and supports quarantine, dead-letter handling, replay, throttling, checkpoints, and operational monitoring.
