# SF blind system reconstruction

## SYSTEM PURPOSE
A version-aware retrieval-augmented generation system that ingests scheduled or event-driven source updates with ACLs, normalizes and classifies content versions, chunks and embeds changed content, publishes synchronized retrieval stores, prepares and executes hybrid user queries with permission filtering and evidence checks, captures coverage feedback, handles ingestion/publication failures, and rebuilds embedding-index generations with atomic promotion and rollback.
