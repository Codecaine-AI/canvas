# SF blind system reconstruction

## SYSTEM PURPOSE
Route inbound phone-support calls through caller lookup, greeting, consented call capture, intent detection, AI self-service when eligible, and human support when needed, while retaining recordings and transcripts for review and using review findings to adjust which intents are allowed for AI handling.
