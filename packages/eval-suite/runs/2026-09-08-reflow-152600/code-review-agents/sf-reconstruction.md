# SF blind system reconstruction

## SYSTEM PURPOSE
A pull-request code-review workflow that resolves and filters PR context, dispatches concurrent autonomous reviewers for correctness, security, performance, test coverage, and API compatibility, merges and verifies findings, publishes comments and a verdict, cancels and restarts work when the branch head changes, and uses telemetry plus human feedback to calibrate later review thresholds.
