# SF blind system reconstruction

## SYSTEM PURPOSE
An event-driven order-processing system that accepts and validates orders, atomically records orders and outbox events, publishes order lifecycle events through a durable event bus, coordinates idempotent payment/inventory/fraud branches, confirms or cancels orders, compensates successful branches after failure, drives fulfillment and shipping, updates customer-facing views, and supports bounded retries, dead-letter repair/replay, and observability.
