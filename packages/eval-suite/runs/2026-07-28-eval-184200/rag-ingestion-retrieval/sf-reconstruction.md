# SF blind system reconstruction

## SYSTEM PURPOSE
A retrieval-augmented generation system that ingests governed source content, extracts and chunks it, builds version-consistent vector/fragment/keyword indexes, performs permission-aware hybrid retrieval for user questions, produces grounded answers with citations or an "I don’t know" response, records feedback and coverage gaps, handles processing failures, and supports atomic embedding-model generation changes.
