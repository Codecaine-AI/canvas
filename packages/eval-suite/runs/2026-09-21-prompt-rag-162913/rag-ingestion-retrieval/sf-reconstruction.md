# SF blind system reconstruction

## SYSTEM PURPOSE
A retrieval-augmented generation workflow that ingests governed sources, preserves provenance, publishes only version-consistent data across vector, document, and keyword stores, retrieves permitted evidence through parallel search, answers with citations or says "I don't know," feeds coverage gaps back into ingestion priorities, and changes model generations through an offline build, atomic promotion, and retained rollback path.
