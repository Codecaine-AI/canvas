# SF blind system reconstruction

## SYSTEM PURPOSE
A retrieval-augmented generation pipeline that ingests changing sources with ACLs, normalizes and versions content, chunks and embeds it, publishes mutually version-consistent vector/fragment/term indexes, retrieves against the current generation, applies user permissions, produces grounded answers with citations, feeds coverage gaps back into ingestion, and rebuilds index generations with atomic promotion or rollback.
