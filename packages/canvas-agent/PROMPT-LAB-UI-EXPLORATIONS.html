Variant 01

Tabbed inspector

Keep a persistent rail, but make it commit to one job at a time.

Design read
  • MovedPrompt health and edit actions sit directly above the XML; Agent, Details, and Revisions become rail tabs.
  • FixesThe rail drops from a stacked dashboard to one focused zone, preserving editor-to-inspector proximity.
  • Trade-offCross-zone facts require a tab switch, and a permanent 320px rail still taxes editor width.

<purpose>
You are the layout editor for a collaborative whiteboard.
Read the board state, infer the user’s spatial intent, and return the smallest safe edit.
Preserve clear grouping, legible labels, and the visual rhythm already established on the board.
</purpose>
<board_model>
The board is an infinite canvas measured in screen-independent pixels from the top-left origin.
<layers>
- frame: a named region that owns layout direction, padding, and child order
- shape: a rectangle, ellipse, note, or freeform object with bounds and style
- connector: a routed relationship with source and target anchors
- label: markdown text attached to a node or positioned independently
</layers>
<selection_rules>
- A primary selection receives resize handles and becomes the edit target.
- Shift-selected nodes move as a set while retaining their relative offsets.
- Locked nodes may be referenced for alignment but must never be mutated.
</selection_rules>
<layout_constraints>
- Keep sibling spacing consistent within a four-pixel tolerance.
- Snap edges and centers only when the resulting intent is unambiguous.
- Route connectors around frames; never cross a label when a clean bend exists.
- Never move an unselected node unless collision avoidance requires it.
</layout_constraints>
</board_model>
<state_grammar>
<input format="json">
- viewport: { x, y, width, height, zoom }
- nodes[]: { id, kind, parentId, bounds, content, style, locked }
- selection[]: ordered node ids, primary first
- history: the most recent user-authored operations
</input>
<output format="xml">
<operation id="op-N" kind="move|resize|create|delete">
- target: one existing node id or a temporary id for creation
- patch: only changed geometry, content, parent, or style fields
</operation>
Explain the intended visual change in one short sentence after the operation list.
</output>
</state_grammar>

Variant 02

Command strip + overlays

Give every horizontal pixel back to the prompt, then layer tools over it only when called.

Design read
  • MovedIdentity, status, actions, and overlay triggers converge in one strip; Agent is a popover and Revisions a bottom drawer.
  • FixesNo permanent rail means the XML reaches its full 120ch measure with room to spare.
  • Trade-offLayered tools can occlude the prompt, and simultaneous overlays require strong dismissal and focus behavior.

Variant 03

Meta column

Keep the important facts visible, but make the column read like a margin—not a control room.

Design read
  • MovedAgent identity, health, revisions, and contextual Details compress into a read-mostly 260px meta column.
  • FixesEverything important is glanceable without tabs, drawers, or competing forms.
  • Trade-offThe column is always present, and unusually long descriptions or revision histories will need careful truncation.

Variant 04

Focus mode

Prompt first, everything else on demand.

Design read
  • MovedThe header collapses to identity; everyday actions float inside the editor; Inspect owns the full stacked panel.
  • FixesThe default state is a quiet, centered prompt with the strongest possible reading and editing focus.
  • Trade-offMetadata disappears at rest, and opening the 360px panel creates the largest single layout shift.

Comparison

The strongest choice depends on whether prompt width, persistent awareness, or low interaction cost matters most during editing.

DimensionV1 · TabsV2 · OverlaysV3 · MetaV4 · Focus
Editor widthWide · about 80%Maximum · full widthWide · about 84%Maximum in focus
GlanceabilityFocused by active tabLow at rest; contextual when openHighest across core metadataPrompt-first; metadata hidden
Interaction costOne tab switchOverlay open and dismissLowestOne Inspect toggle
Crowding riskModerate permanent railLow at rest; high when layeredSteady but containedLowest closed; high when open
