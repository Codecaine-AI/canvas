Palette proposals — current / muted / jewel / hot rod

Three re-aims of the 10-pick canvas palette. Option A (muted MW2) anchors every hue to the Modern Warfare 2 camo assets — verdict: reads too dull. Option B (jewel) sits between A and the current candy palette: same deep, uniform lightness ladder as A, but chroma pushed back up into a jewel register — carmine, ember, gold, emerald, cobalt — rich and luminous without going neon. Option C (hot rod) answers "B is still too dull": brighter and cleaner — racing red, flame orange, kelly green, and a deep rich cobalt blue — bright-and-clean emblem color, not candy and not metal-flake. Same 10 slot ids, same ink / fill / wash roles in every option; documents store swatch ids, so no migration either way.

Ladders — A: ink L 0.520, C 0.055–0.111 · B: ink L 0.550, C 0.094–0.165 · C: ink L 0.575, C 0.098–0.210 (flame/gold ride L 0.615/0.625 where the sRGB gamut opens; cobalt dips to L 0.520 for depth) · current: ink L 0.56–0.76, C 0.095–0.254. Fills: A 0.900 / B 0.895 / C 0.900. All values in sRGB gamut.

Green section + chip, yellow and blue stickies, green / red / orange shapes at the universal 4px stroke, gray connectors.

Threshold: 3:1 (WCAG non-text contrast). Six of nine current inks miss it. Every A ink clears 4.88, every B ink clears 4.17, every C ink clears 3.29 — all three fix the legibility gap; C spends the most contrast headroom on saturation and stays legal. Black object text on every A/B fill and sticky measures 14.9–15.8:1.



How the options differ



  
Same discipline, more voltage. B keeps the one-lightness-per-role ladder (ink L 0.550, fill 0.895, sticky 0.860, wash 0.972) so no pick shouts — but ink chroma rises from A’s 0.055–0.111 to 0.094–0.165, roughly the midpoint between A and the current palette’s 0.095–0.254.

  
Hues shift from earth to gem. A’s camo hues (orange 55° brown, yellow 90° olive-gold, green 130° olive) move to jewel positions in B: carmine 25°, ember 50°, gold 85°, emerald 150°, deep teal 195°, cobalt 260°, violet 297°, orchid 345°. Gray flips from warm gunmetal to cool slate (270°) to complement the jewel tones.

  
Yellow and teal are gamut-limited. At L 0.55, sRGB tops out at C 0.113 for gold and 0.094 for teal — the ladder takes the max available rather than lightening the ink, so those two stay slightly quieter than their neighbors by physics, not by choice.

  
C — hot rod, in short. B’s hues kept (red 27°, flame 55°, gold 88°, kelly 150°, teal 195°, cobalt 262°, violet 297°, flamingo 350°) but chroma raised to the top of what sRGB allows at ink depth: Racing Red C 0.200, Cobalt C 0.210 at a deeper L 0.520 — the one deliberate ladder break, so the main blue reads truly rich. Flamingo stays the quietest chromatic pick; if pink should go further toward neutral (or be retired from the picker), that is a one-cell decision.

  
Unchanged in all options: slot ids, role structure, resolvers, black object text, white’s borrowed gray stroke. To apply either: swap the table cells in packages/canvas/src/theme/palette.ts and update the lock table in palette.test.ts.
